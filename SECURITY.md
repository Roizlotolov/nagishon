# Security

nagishon is provided as is, without warranty or support obligation.

`nagishon` makes no network requests, sets no cookies and has no runtime dependencies; the only state it keeps is the user's chosen adjustments in `localStorage`. If you find a security issue, please report it privately through GitHub (Security tab of `Roizlotolov/nagishon`, "Report a vulnerability"), or open an issue without exploit details. Reports are read on a best-effort basis; there is no response-time commitment.
