# Widget contrast verification

Generated by `node scripts/check-contrast.mjs --markdown` (WCAG 2.x relative luminance). Text pairs need 4.5:1, UI components and focus rings 3:1. The script exits 1 when any pair fails.

Custom `theme.accent`/`background`/`foreground` values are the integrator's responsibility; the widget only picks a black or white text color for a custom accent.
