# Own button

**עברית:** הכפתור הצף מוסתר, וקישור "נגישות" בפוטר פותח את התפריט עם `Nagishon.get().open()`. בסגירה (Escape או כפתור הסגירה) המיקוד חוזר אל הקישור. פתחו את `index.html`.

**English:** The floating launcher is hidden; a footer "נגישות" link opens the dialog with `Nagishon.get().open()`. On close, focus returns to that link. Open `index.html`.
