# Events and state

**עברית:** האזנה ל־`nagishon:ready` ול־`nagishon:change`, הדפסת המצב ל־`<pre aria-live="polite">`, וכפתורים שקוראים ל־`setState` ול־`reset`. פתחו את `index.html`.

**English:** Listens to `nagishon:ready` and `nagishon:change`, logs the state into a `<pre aria-live="polite">`, and has buttons calling `setState` and `reset`. Open `index.html`.
