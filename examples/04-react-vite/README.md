# React + Vite

**עברית:** `NagishonWidget` עם `launcher={{ hidden: true }}`, כפתור "הגדרות נגישות" משלכם בכותרת שקורא ל־`open()` מ־`useNagishon()`, ושורה שמציגה את `state.textScale`. להרצה: `npm install && npm run dev` בתיקייה זו (נדרשים גם `tsconfig.json` ו־`vite.config.ts` עם `@vitejs/plugin-react`, כמו בכל תבנית Vite).

**English:** `NagishonWidget` with a hidden launcher, a custom "הגדרות נגישות" header button calling `open()` from `useNagishon()`, and a line showing `state.textScale`. To run: `npm install && npm run dev` in this folder (add the usual Vite `tsconfig.json` and `vite.config.ts` with `@vitejs/plugin-react`).
