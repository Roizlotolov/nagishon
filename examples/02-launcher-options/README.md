# Launcher options

**עברית:** רצועת כפתורים שמפעילה מחדש את התפריט עם אפשרויות שונות (`position`, `offset`, `shape`, `size`, `icon`, `style`, `theme.accent`, `theme.preset`) באמצעות `destroy()` ואז `init()`. הסקריפט נטען עם `data-nagishon-manual`. פתחו את `index.html`.

**English:** A button strip re-initialises the widget with different launcher and theme options via `destroy()` then `init()`. The script loads with `data-nagishon-manual`. Open `index.html`.
