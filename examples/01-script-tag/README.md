# Script tag

**עברית:** ההתקנה הפשוטה ביותר: סקריפט pre-paint ב־`<head>` ותג סקריפט אחד לפני `</body>` עם `data-statement-url`. פתחו את `index.html` בדפדפן.

**English:** The simplest install: the pre-paint script in `<head>` and one script tag before `</body>` with `data-statement-url`. Open `index.html` in a browser.
