# Next.js (App Router)

**עברית:** דוגמת App Router: סקריפט ה־pre-paint ב־`<head>`, `NagishonWidget` ב־layout, ועמוד שלד להצהרת נגישות ב־`/accessibility`. להרצה: `npm install && npm run dev` בתיקייה זו (נדרש `tsconfig.json`, ש־Next יוצר אוטומטית בהרצה הראשונה). התיקייה נקייה מקבצי קונפיגורציה כדי להישאר קצרה.

**English:** App Router example: the pre-paint script in `<head>`, `NagishonWidget` in the layout, and a skeleton accessibility statement page at `/accessibility`. To run: `npm install && npm run dev` in this folder (Next creates `tsconfig.json` on first run). Config files are omitted on purpose to keep it short.
