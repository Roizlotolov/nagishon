**הרצה (עברית):** דוגמאות ה־HTML רצות בפתיחת הקובץ בדפדפן או בכל שרת סטטי. הסקריפט נטען מ־jsDelivr, ולכן נדרשת רשת. לעבודה ללא רשת: הריצו `npm run build` בשורש הריפו והחליפו את ה־`src` ל־`../../dist/nagishon.iife.js` (ואת ה־pre-paint ל־`../../dist/prepaint.js`). דוגמאות 3 ו־4 דורשות `npm install` בתיקייה שלהן.

**Running (English):** the HTML examples run by opening the file or with any static server. The script loads from jsDelivr, so they need network. To work offline, run `npm run build` at the repo root and replace the `src` with `../../dist/nagishon.iife.js` (and the pre-paint one with `../../dist/prepaint.js`). Examples 3 and 4 need `npm install` in their own folder.
